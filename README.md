# FrameLoop

같은 구도로 사진을 반복 촬영하고 시간에 따른 변화를 비교하는 iOS·Android 앱입니다.

## 구현된 기능

- 변화 프로젝트 생성 및 카테고리 분류
- 카메라 촬영과 사진첩 가져오기
- 이전 사진 반투명 오버레이와 촬영 격자
- 앱 내부 영구 저장과 프로젝트별 타임라인
- 원하는 두 사진 나란히/겹쳐 비교
- 전체 사진 순차 재생 및 자연스러운 전환
- 서버 업로드 없는 기기 내 1080p MP4 생성·저장·공유

## 개인정보와 저장

- 회원가입 없이 바로 사용합니다.
- 사진과 프로젝트는 사용자의 휴대폰 앱 저장공간에만 보관됩니다.
- 영상도 휴대폰 안에서 생성되며 사진을 서버로 전송하지 않습니다.
- 앱을 삭제하면 기록을 복구할 수 없으므로 중요한 완성 영상은 사진 앱에 저장해야 합니다.

## 실행

```bash
npm install
npx expo start
```

촬영·비교·재생은 Expo Go에서 확인할 수 있습니다. 기기 내 MP4 생성은 로컬 네이티브 모듈을 사용하므로 EAS development/production 빌드에서 확인합니다.

## 출시 빌드

```bash
npx eas-cli build --platform all --profile production
```

영상 생성은 사진 2~60장, 세로 1080p, 최대 15초로 제한해 발열과 메모리 사용을 관리합니다.
