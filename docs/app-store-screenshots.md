# FrameLoop 앱스토어 화면 캡처 계획

실제 iPhone 빌드가 만들어진 뒤 아래 순서로 6.7인치 iPhone 캡처를 준비합니다. 화면 위에 별도 광고 문구나 기능을 과장하는 문구는 넣지 않습니다.

1. 홈 화면
   - 캡션: 작은 변화를 매일 기록해보세요
   - 보여줄 요소: 프로젝트 카드, 기록 일수, 사진 수

2. 같은 구도 촬영
   - 캡션: 이전 사진을 겹쳐 더 정확하게 촬영
   - 보여줄 요소: 카메라 화면, 격자, 이전 사진 투명도 조절

3. 사진 비교
   - 캡션: 원하는 두 순간을 나란히 비교
   - 보여줄 요소: 두 사진 선택, 나란히/겹쳐보기 전환

4. 타임라인 재생
   - 캡션: 처음부터 지금까지 자연스럽게 재생
   - 보여줄 요소: 썸네일 타임라인, 속도, 부드럽게/딱딱하게 전환

5. 변화 영상 만들기
   - 캡션: 기록을 세로 1080p 영상으로 저장
   - 보여줄 요소: 진행률, 사진 앱 저장·공유 버튼

6. 보관함
   - 캡션: 나의 모든 기록을 한곳에 보관
   - 보여줄 요소: 프로젝트와 사진 목록

## 캡처 시 주의

- 실제 앱에서 촬영한 사진을 사용합니다.
- 개인정보가 보이는 사진은 사용하지 않습니다.
- 상태 표시줄 시간·배터리·통신 상태는 Apple 캡처 규칙에 맞게 정리합니다.
- 영상 생성 기능은 EAS iOS 빌드에서 확인한 뒤 캡처합니다.
