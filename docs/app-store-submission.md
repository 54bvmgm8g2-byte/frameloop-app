## 한국어 설명

같은 구도로 사진을 남기고, 시간이 지나며 달라지는 모습을 한눈에 확인해보세요.

FrameLoop는 머리 기르기, 운동 변화, 반려동물의 성장, 공간 정리처럼 반복해서 기록하고 싶은 순간을 위한 변화 기록 앱입니다.

주요 기능
- 이전 사진을 반투명하게 겹쳐 보며 같은 구도로 촬영
- 사진을 원하는 두 시점으로 나란히 또는 겹쳐 비교
- 처음부터 마지막까지 타임라인 순서로 재생
- 사진 사이를 부드럽게 전환하거나 딱 끊어서 재생
- 선택한 사진으로 세로 1080p 변화 영상 만들기
- 프로젝트와 사진을 휴대폰에 저장

FrameLoop는 회원가입과 광고 없이 사용할 수 있습니다. 사진과 프로젝트는 서버로 전송하지 않고 사용자의 기기에 저장됩니다. 앱을 삭제하면 앱 안에 저장된 기록이 삭제될 수 있으므로, 완성한 영상은 사진 앱에 저장해 주세요.

## 심사 메모 초안

FrameLoop는 사진을 촬영·가져와 기기 안에 저장하고, 사용자가 선택한 사진을 비교하거나 영상으로 변환하는 앱입니다. 계정, 서버 업로드, 광고, 사용자 간 소통 기능은 없습니다. 카메라와 사진 접근 권한은 사용자가 기록을 만들거나 사진을 가져오고 저장할 때만 요청합니다.
